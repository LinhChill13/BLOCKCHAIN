# Charity DApp - Tổng quan Dự án

## 💡 Ý nghĩa & Mục tiêu Dự án
* **Bản chất hệ thống:** Là ứng dụng phi tập trung (DApp) quản lý quỹ từ thiện minh bạch bằng Smart Contract trên hệ sinh thái EVM[cite: 1].
* **Vấn đề giải quyết:** Dự án giải quyết triệt để bài toán thất thoát và gian lận từ thiện[cite: 1].
* **Phương thức cốt lõi:** Tự động hóa quy trình giải ngân theo từng mốc (milestone) dự án và xác thực minh chứng thông qua hệ thống lưu trữ phi tập trung[cite: 1].
